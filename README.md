# AccessAI

AI-Powered Accessibility Detection and Route Recommendation on Penn State's Campus

## Project Description

AccessAI aims to explore accessibility-aware route recommendation on Penn State's campus. Our project will build from existing research in sidewalk accessibility detection and routing.

## Parent Paper

Towards Fine-Grained Sidewalk Accessibility Assessment with Deep Learning: Initial Benchmarks and an Open Dataset

https://dl.acm.org/doi/10.1145/3663548.3688531

# Dataset

We are using the validated Project Sidewalk dataset associated with our parent paper.

## Current Direction

We are using the parent paper's sidewalk accessibility detection work as the starting point for our project. Future work will explore how accessibility information can be incorporated into route recommendation, including changing conditions and confidence in accessibility predictions.
